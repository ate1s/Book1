# Chapter 1 — illustration plan

Target: 60–85 illustrated shots, not eight static slides. The timeline must be aligned to final narration, not evenly distributed.

## Visual beats (working, verify against full original text)
- World introduction: landscape, forests, mountain passes, establishing shots.
- Alexander: close-up, injuries, environment and reactions.
- Captivity: wagon/truck interior, other captives, guards, movement.
- Eugene: first appearance, red curls, glasses, reactions, alternating close-ups.
- Communication: speaker-specific over-shoulder shots; only switch on actual dialogue.
- Unusual light: lamp insert, color change, reaction shots.
- Stop: exterior, vehicle movement, tension.

## Editing rules
1. Each scene must contain an anchor to the original chapter and a start/end time.
2. Prefer a new shot for every meaningful action or emotional beat.
3. During conversation use alternating medium, close and reaction shots; never change the face reference.
4. Never invent a new event to fill a visual gap.
5. After voice generation, use word alignment and manual review for the final JSON.
6. 16:9 landscape, 1280×720 minimum. Character designs require approval before bulk rendering.

This is a shot-planning guide, not a claim that final illustrations exist.
