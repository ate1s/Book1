# Character continuity

This is a production checklist, not a substitute for approved reference images.

- Alexander: blond hair, blue eyes, bruised jaw in opening scenes. Preserve face and proportions across angles.
- Eugene (Éжен): curly red hair, round glasses. Preserve the same glasses, face and hairstyle.
- Visual direction: cinematic photorealistic graphic novel, consistent lighting and costume per scene.
- Every scene record should point to a single approved character reference and a description grounded in the source.
- Do not invent plot events from scene titles.
