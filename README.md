# Book1 — видеокомикс «Сожжённые земли. Лишний»

Проект автоматизированной адаптации глав книги в видеокомикс.

## План
1. EPUB → главы и сцены.
2. Озвучка рассказчика и персонажей.
3. Привязка иллюстраций к событиям и таймкодам.
4. Сборка MP4 через FFmpeg в GitHub Actions.

Материалы книги и референсы персонажей добавляются отдельно. Не загружайте текст книги в публичный репозиторий без соответствующих прав.
